# 隐私与本地数据

## 本地保存

Debian 安装版使用以下目录：

- 项目、配置和 API Key：`~/.local/share/best-yolo`
- 启动日志：`~/.local/state/best-yolo/start.log`
- 缓存：`~/.cache/best-yolo`

API Key 只存在全局状态文件中，不复制到每个项目配置；状态文件权限固定为 `600`。Key 当前是本地明文保存，因此不要分享 `.gui_state.json`，也不要把整个用户数据目录上传到 Issue。

## 网络请求

程序不会在后台自动上传项目。以下操作会向用户配置的接入点发送数据：

- 自动标注：发送正在处理的图片和目标类别提示词。
- AI 补充提示词：发送用户勾选的对照图、类别描述和有限的调整历史。
- 获取模型：请求接入点的模型列表。

具体数据处理规则由所配置的 API 服务提供方决定。

## Release 内容

公开构建只包含白名单源码和运行依赖，不包含 `.venv`、API Key、个人路径、项目、图片、标签、日志、模型权重或历史输出。
