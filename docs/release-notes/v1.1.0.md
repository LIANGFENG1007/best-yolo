# Best yolo v1.1.0

[查看全部版本、更新内容与历史安装包](https://github.com/LIANGFENG1007/best-yolo/blob/main/docs/releases.md)

## 新增功能

- 每次启动后在后台自动检查 GitHub 最新稳定版，不阻塞主界面。
- 左上角新增更新入口：没有新版本时显示蓝色“检测更新”，发现新版本时显示红色“发现更新”。
- 点击“发现更新”可查看新版本号与完整中文更新内容。
- 更新弹窗提供“前往 GitHub 发布页”按钮，用户自行决定是否下载和安装。
- 蓝色“检测更新”支持手动重新检查，并明确提示“已经是最新版”或“没有网络”。
- “检测软件更新”纳入快捷键设置，默认快捷键为 `Ctrl+Alt+U`；可与其他 77 个命令一起搜索和修改。

## 修复内容

- 修复断网、GitHub 不可达或返回内容异常时，更新检查可能干扰程序启动的问题；自动检查失败时现在完全静默。
- 修复点击发布页时无法区分浏览器打开失败和网络不可用的问题。
- 修复部分功能弹窗可能无法打开的潜在问题。

## Windows 10 / 11 x64

下载 `BestYolo-Setup-1.1.0-win64.exe`，双击后按向导安装。安装位置可以自行选择；安装包包含 Python、Qt、OpenCV 和微软 VC++ 运行库。

## Ubuntu 22.04 x86_64

下载 `best-yolo_1.1.0-1_amd64.deb` 后运行：

```bash
sudo apt install ./best-yolo_1.1.0-1_amd64.deb
```

## 下载文件

- `BestYolo-Setup-1.1.0-win64.exe`：Windows 10/11 x64 安装程序。
- `BestYolo-Setup-1.1.0-win64.exe.sha256`：Windows 安装程序校验文件。
- `INSTALL-Windows10-zh-CN.txt`：Windows 中文离线安装说明。
- `best-yolo_1.1.0-1_amd64.deb`：Ubuntu 22.04 amd64 安装包。
- `best-yolo_1.1.0-1_amd64.deb.sha256`：Ubuntu 安装包校验文件。
- `INSTALL-Ubuntu22.04-zh-CN.txt`：Ubuntu 中文离线安装说明。

更新检查只读取 GitHub 上的公开版本信息，不会自动下载安装包，也不会发送 API Key、项目路径、图片或标签。
