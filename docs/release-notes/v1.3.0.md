# Best yolo v1.3.0

[查看全部版本、更新内容与历史安装包](https://github.com/LIANGFENG1007/best-yolo/blob/main/docs/releases.md)

## 新增功能

- 左下角新增彩色调色盘入口。图标无需文字也能直接识别，鼠标停留时会显示功能名和快捷键。
- 内置 8 套一键主题：经典黑、经典白、流金黑、玫瑰红、极光蓝、翡翠绿、冰川青和暮光紫。
- 支持分别修改界面底色、侧边栏、面板、输入区域、主要文字、次要文字和按钮强调色。
- 自定义调色提供圆形 HSV 全色调色盘、亮度滑条、十六进制颜色值和随当前颜色项目变化的推荐色。
- 设置窗口提供实时界面缩略预览；应用后主窗口立即换肤，关闭并重新打开软件后仍会恢复上次配色。
- “打开界面配色”已纳入快捷键设置，默认快捷键为 `Ctrl+Alt+T`；当前共有 79 个可配置命令。

## 修复内容

- 修复使用浅色主题时输入框、表格、日志、状态栏和滚动条可能残留固定深色的问题。
- 修复用户把按钮设置为浅色或深色后，按钮文字对比度不足的问题；现在会自动选择黑色或白色文字。
- 成功、警告、删除、停止、错误和发现更新等带有功能含义的按钮会根据当前背景自动调整，但继续保留绿、黄、红等识别语义。
- 修复切换主题后，已经显示的状态文字、表格项和列表项可能仍使用旧颜色的问题。
- 损坏或不完整的主题配置会自动回退到可用默认值，不影响程序启动。

## Windows 10 / 11 x64

下载 `BestYolo-Setup-1.3.0-win64.exe`，双击后按向导安装。安装位置可以自行选择；安装包包含 Python、Qt、OpenCV 和微软 VC++ 运行库。

## Ubuntu 22.04 amd64

下载 `best-yolo_1.3.0-1_amd64.deb` 后运行：

```bash
sudo apt install ./best-yolo_1.3.0-1_amd64.deb
```
