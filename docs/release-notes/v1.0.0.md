# Best yolo 首个公开版本

Best yolo 是一款面向 YOLO 数据集制作的桌面工具，支持 Qwen-VL 自动标注、人工精修、AI 补充提示词、视频抽帧和数据集导出。

[查看全部版本、更新内容与历史安装包](https://github.com/LIANGFENG1007/best-yolo/blob/main/docs/releases.md)

## 新增功能

- Qwen-VL 批量自动标注与原图人工精修。
- AI 根据人工修订结果补充类别提示词。
- 视频区间抽帧和 YOLO 数据集导出。
- 77 个功能命令的可搜索、自定义快捷键设置。
- Windows 10/11 x64 与 Ubuntu 22.04 amd64 安装包。

## 修复内容

- 修复 AI 补充提示词页面无法滚动以及模型下拉搜索问题。
- 修复 Debian 安装权限、API Key 保存、空负样本重复处理和类别映射问题。
- 修复 Windows 冻结版后台任务启动与中文数据导出编码问题。
- 修复云端 API 安装版错误依赖本地 PyTorch 工具的问题。

## Windows 10 / 11 x64

下载 `BestYolo-Setup-1.0.0-win64.exe`，双击后按向导安装。安装位置可以自行选择，安装包已包含 Python、Qt、OpenCV 和微软 VC++ 运行库，全新系统无需预装开发环境。

在 PowerShell 中核对安装包：

```powershell
(Get-FileHash .\BestYolo-Setup-1.0.0-win64.exe -Algorithm SHA256).Hash
Get-Content .\BestYolo-Setup-1.0.0-win64.exe.sha256
```

当前安装程序未使用商业代码签名证书。若 SmartScreen 提示未知发布者，请先确认以上两个 SHA256 一致。

## Ubuntu 22.04 x86_64

下载 `.deb` 和同名 `.sha256` 文件后运行：

```bash
sha256sum -c best-yolo_*.deb.sha256
sudo apt install ./best-yolo_*_amd64.deb
```

安装完成后，在应用菜单搜索 **Best yolo**，或在终端运行 `best-yolo`。
