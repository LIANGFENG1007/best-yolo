# Best yolo v1.3.2

[查看全部版本、更新内容与历史安装包](https://github.com/LIANGFENG1007/best-yolo/blob/main/docs/releases.md)

## 新增功能

- 视频切片页右侧设置区增加独立滚动容器。窗口高度不足或用户放大界面后，可以在右侧继续向下查看所有设置和切好的图片。
- “停止”“打开切分文件夹”“用这批图去标注”等按钮采用自动换行布局，高缩放时仍能完整显示。

## 修复内容

- 修复界面缩放后右侧设置卡使用旧布局高度，造成“视频与输出”“开始”“抽帧设置”和“切好的图”互相重叠的问题。
- 修复抽帧间隔、图片格式、文件名和复选框被挤压、文字被裁切的问题。
- 修复小窗口或较大缩放比例下，右侧底部刷新按钮和切片缩略图不可见的问题。
- 在 90%、100%、110%、125%、140% 和 160% 缩放比例以及最小窗口尺寸下，设置卡保持完整高度和正常间距。
- 鼠标停在没有获得焦点的抽帧数字框或下拉框上时，滚轮会继续滚动右侧设置区，同时不会改变输入值。

## Windows 10 / 11 x64

下载 `BestYolo-Setup-1.3.2-win64.exe`，双击后按向导安装。安装位置可以自行选择；安装包包含 Python、Qt、OpenCV 和微软 VC++ 运行库。

## Ubuntu 22.04 amd64

下载 `best-yolo_1.3.2-1_amd64.deb` 后运行：

```bash
sudo apt install ./best-yolo_1.3.2-1_amd64.deb
```
