# Best yolo v1.3.1

[查看全部版本、更新内容与历史安装包](https://github.com/LIANGFENG1007/best-yolo/blob/main/docs/releases.md)

## 新增功能

- 每个新版本第一次被自动检测到时，会主动弹出一次完整更新内容。软件会记住已经提示过的版本，以后启动不会重复弹出；用户仍可点击左上角“发现更新”再次查看。
- 更新弹窗新增完整的 GitHub Release 地址。地址可以直接点击，也可以使用“复制链接”后粘贴到任意浏览器。
- 弹窗明确注明：如果无法自动跳转，请自行打开发布页下载对应系统的安装包。

## 修复内容

- 修复软件已经通过 GitHub API 获取到最新版本，但点击“前往 GitHub 发布页”仍可能错误显示“没有网络”的问题。
- 删除打开浏览器前重复发起的 Release 网页连通性探测。按钮现在直接调用 Windows 或 Linux 配置的系统默认浏览器。
- 如果系统没有配置可用的默认浏览器，会保留更新弹窗并显示手动访问地址，不再把浏览器调用失败误判为网络中断。
- 自动检查断网时仍保持静默；只有用户主动点击“检测更新”失败时才显示网络提示。

## Windows 10 / 11 x64

下载 `BestYolo-Setup-1.3.1-win64.exe`，双击后按向导安装。安装位置可以自行选择；安装包包含 Python、Qt、OpenCV 和微软 VC++ 运行库。

## Ubuntu 22.04 amd64

下载 `best-yolo_1.3.1-1_amd64.deb` 后运行：

```bash
sudo apt install ./best-yolo_1.3.1-1_amd64.deb
```

## 下载文件

- `BestYolo-Setup-1.3.1-win64.exe`：Windows 10/11 x64 安装程序。
- `BestYolo-Setup-1.3.1-win64.exe.sha256`：Windows 安装程序校验文件。
- `INSTALL-Windows10-zh-CN.txt`：Windows 中文安装说明。
- `best-yolo_1.3.1-1_amd64.deb`：Ubuntu 22.04 amd64 安装包。
- `best-yolo_1.3.1-1_amd64.deb.sha256`：Ubuntu 安装包校验文件。
- `INSTALL-Ubuntu22.04-zh-CN.txt`：Ubuntu 中文安装说明。

发布版只读取 GitHub 的公开版本信息，不会自动下载安装包，也不会发送 API Key、项目路径、图片或标签。
