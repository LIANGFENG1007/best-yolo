# Contributing

Issues and focused pull requests are welcome for reproducible bugs, usability improvements, documentation, and tests.

Before opening a pull request:

1. Keep generated data, credentials, model weights, `.venv`, and `dist/` out of commits.
2. Run `gui/test_gui.py` and `gui/test_shortcuts.py`.
3. Describe the user-visible problem and the resulting behavior.
4. Include screenshots for layout changes at both `1536×832` and `900×700` when relevant.

The repository does not yet grant an open-source license. Discuss substantial reuse or redistribution with the maintainer before relying on rights beyond GitHub review and contribution workflows.
